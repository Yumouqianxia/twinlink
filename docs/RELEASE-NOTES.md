同频 TwinLink v0.0.1 是首个公开预发布版本，尚非正式版。

- 配对码建立双人房间，无需输入对方 IP。
- 本地聊天历史、加密离线消息、投递回执。
- 需接收方同意的加密文件传输、断点续传、同名不覆盖。
- GitHub 固定更新源，签名校验，更新后重启并保留本地记录。

首次使用需要管理员提供服务器设置码。公开下载不附带私有服务器凭据。
目前文件统一经过 HTTPS 离线信箱，暂存最多 7 天、单文件最大 1 GiB。
局域网游戏/TUN 模式尚未提供。macOS 为 ad-hoc 签名、未公证；Windows 安装包未使用商业代码签名证书，系统可能提示未知发行者。CI 构建通过不等于已完成两台不同网络设备的实测。

应用不会自动安装新版本；发现更新后，请到“设置 → 应用更新”确认更新并重启。
