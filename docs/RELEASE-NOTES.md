同频 TwinLink v0.0.2 · 预发布版，尚非正式版。

- 修复 Windows 下载目录不可用时，启动回调报 `unknown path` 并直接退出的问题。此时改用应用数据目录内的接收文件夹，可在设置中更改。
- 启动失败显示明确提示，并记录本地启动日志，便于定位 WebView2、路径和数据库初始化问题；不记录聊天内容、配对码或服务器令牌。
- 发布前增加实际 Windows 安装包的正常启动、下载目录异常启动、损坏数据库受控退出和前端 IPC 就绪检查；任一检查失败不会发布或推进更新源。
- 修正 macOS 图标透明边距，使其与其他应用的视觉尺寸接近。

Windows 启动日志：`%LOCALAPPDATA%\TwinLink\logs\startup.log`；若该目录无法写入，回退到 `%TEMP%\TwinLink\logs\startup.log`。
本机 Windows 11 x64 已从源码构建并实际安装，确认原生界面、设置页和真实 Tauri IPC 正常。无法进入 v0.0.1 时，请下载 v0.0.2 完整安装包手动升级，不能依赖应用内更新。

本次确认并修复了下载目录异常这一闪退路径，不能据此认定所有电脑的闪退原因相同。局域网游戏模式仍未提供；macOS 未公证，Windows 未使用商业代码签名证书。
