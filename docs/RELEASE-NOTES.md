同频 TwinLink v0.0.3 · 预发布版，尚非正式版。

- 调整桌面工作区与按钮对齐；新增外观面板，支持四套内置主题、系统明暗、自定义强调色与字号，以及本地 JSON 主题包的导入、编辑、导出和删除。
- 聊天中显示文件邀请、接收确认、传输进度和完成记录；文件与文字按持久化时间交错排列，发送文件后保留聊天页面。
- 输入框提供独立的文件和图片入口，支持桌面原生拖拽发送。图片在本地可用时显示缩略图，点击放大，支持 Escape 关闭；收到的图片须接收完成后才能预览。
- 双方直连时先征求接收同意，再通过 P2P 流式传输，不预上传服务器，不设应用文件大小上限；无法直连时使用加密离线信箱，单文件上限 1 GiB。接收默认询问，可在设置开启当前房间自动接收。
- 设置中新增本地数据导出和导入，覆盖聊天、传输记录与已保存房间/服务器配置；合并去重、保留本机接收目录、暂停连接且不重放旧发送队列。
- 保留 v0.0.2 的 Windows 下载目录异常启动修复、启动失败提示和日志，以及 macOS 图标边距修正。

图片预览支持 PNG、JPEG、GIF、WebP，最大 20 MiB、单边 16,384 像素、总计 4,000 万像素。该限制只影响预览，不限制 P2P 原文件大小。图片预览依赖本机文件，移动或删除后可能失效。备份不包含附件本体，且未加密，包含房间和服务器凭据，请妥善保管。

构建、核心真实回环传输与隔离浏览器界面回归已通过。跨公网双机连接、Windows/macOS 原生图片预览与原生文件选择器仍待人工实测；浏览器预览不提供真实传输。发布流程要求三套平台构建、更新包签名与 Windows 安装启动检查全部通过后才更新下载与更新清单。

更新源固定为本仓库的 GitHub 发布包及更新清单，安装须用户确认并重启。若旧版无法启动，请下载完整安装包手动升级；正常升级保留应用数据。

局域网游戏模式仍未提供；macOS 使用 ad-hoc 签名且未公证，Windows 未使用商业代码签名证书。
